Сдачу на платформе выполняет Мовсар. Этот файл описывает материалы, а не подтверждает отправку заявки.

## Короткое описание для формы

Контур помогает закупщику проверить спецификацию электротоваров перед покупкой. Он извлекает строки из документов, сопоставляет их с каталогом и остатками выбранного склада, показывает конфликтующие характеристики и формирует предложение. Человек проверяет состав и подтверждает его; сервер повторно сверяет цену и остаток, затем сохраняет корзину. Демонстрация запускается локально без API-ключей.

Отличительный пример: описание артикула `200300285_` указывает 160 А, а характеристика — 250 А. Контур показывает оба значения и блокирует предложение по списку. После исключения спорной строки пользователь подтверждает две единицы учебного товара общей стоимостью 122 000 ₸. Это стоимость корзины, а не измеренная экономия.

## Что учесть при отправке

- Репозиторий приватный: проверить доступ проверяющих, не меняя публичность по предположению.
- Если форма принимает файлы, загрузить MP4; ссылка GitHub на файл сама по себе не является публичным видеохостингом. HTML-презентацию открывать локально вместе с её шрифтами и изображениями из клона.
- Публичное развёртывание не выполнялось. `localhost` — адрес локального запуска, его нельзя передавать как адрес доступного жюри сайта.
- Каталог содержит 10 сохранённых карточек партнёра и 3 учебные позиции; корзина локальная, оплата и резервирование не выполняются.
- Реальные OpenAI/OCR, чистый Windows 11 и Docker Compose проверены Даниялом через Codex на указанных в [FINAL-QA.md](FINAL-QA.md) версиях. Демо и тестовый клиент не считаются доказательством live-вызова.
- После синхронизации интегрированный `3757794` отдельно проверен в чистом Windows-клоне. Прежние live CLI, 262 теста и Docker измерены на `988434a` до rebase; точные границы результатов сохранены в отчёте. Итоговый commit документации после rebase фиксируется отдельно.
- Для автономного показа используйте `uv run hack serve --mode demo`; если live-сервер занимает порт 8000 — `uv run hack serve --mode demo --port 8001`. Демосервер по умолчанию использует ту же БД; для новой корзины откройте отдельный профиль браузера.

После отправки сохранить подтверждение платформы. Коммит и push подтверждают публикацию кода, но не сдачу заявки.
