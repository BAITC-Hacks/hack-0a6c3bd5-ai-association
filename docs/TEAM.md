Общий репозиторий организатора: [BAITC-Hacks/hack-0a6c3bd5-ai-association](https://github.com/BAITC-Hacks/hack-0a6c3bd5-ai-association). Каждый участник сохраняет собственное авторство коммитов. API согласуется через [контракт](API-CONTRACT.md), продуктовый объём — через [SPEC.md](SPEC.md); рабочие правила находятся в [AGENTS.md](../AGENTS.md).

Перед синхронизацией проверить `git status`; при чистом дереве получить изменения `git pull --rebase origin main`. Добавлять в коммит только свою проверенную работу. Изменения общих файлов согласовывать, конфликты разбирать совместно; force push не используется. Интегрированная версия и собранный `web/dist` отправляются в `main` после проверки.

Почасовая договорённость: A передаёт проверенный результат к :50, B интегрирует его и обновляет [PROGRESS.md](../PROGRESS.md) к :55. Журнал использования Codex — [codex-log.md](codex-log.md). Разработка интерфейса с Claude и последующая интеграция отражены в истории Git и журнале.

Ключи API, cookie, `.env` и локальная БД не входят в Git. Деморежим запускается без личных доступов. Установка и демонстрационный сценарий — в [README](../README.md); фактически выполненные финальные проверки — в [FINAL-QA.md](FINAL-QA.md).
