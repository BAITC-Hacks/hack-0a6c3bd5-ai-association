# H3: демонстрация на 90 секунд

API-сценарий проверен на четырёх демонстрационных файлах. Полная цепочка через браузер проверена на компьютере и телефоне; ниже — сценарий для репетиции защиты. Это ещё не запись трёх финальных репетиций H5.

**Подготовка.** Запустить приложение по README в `DEMO_MODE=1`. Открыть новое окно инкогнито без других окон инкогнито этого браузера либо отдельный профиль, чтобы начать с новой сессии и пустой корзины. Выбрать склад «Астана». Кнопка сброса сессии для сценария не требуется.

| Время | Действие | Что показать и сказать |
| --- | --- | --- |
| 0–15 с | Открыть `http://127.0.0.1:8000/?view=upload`, скачать `sample.xlsx` и загрузить его в приложение. | «Загружаем спецификацию. Этот сценарий работает без сети и API-ключей». |
| 15–25 с | Показать две извлечённые строки: `DEMO-160-AVAILABLE` — 2 шт; `200300285_` — 1 шт. | «Перед подбором человек видит и проверяет названия, количества и единицы». |
| 25–40 с | Нажать «Проверить по каталогу». | Во второй строке обнаружен конфликт номинального тока: 160 / 250 А. Предложение для всего файла не создано, корзина пуста. «Противоречие нельзя молча пропустить». |
| 40–55 с | Нажать «Исправить строки», исключить строку 2 и повторно нажать «Проверить по каталогу». | Осталась одна проверенная позиция. Исключение означает, что спорный товар не войдёт в предложение. |
| 55–70 с | Проверить предложение: `DEMO-160-AVAILABLE`, 2 шт, по 61 000 ₸, всего 122 000 ₸. Затем подтвердить его. | «Только отдельное подтверждение меняет корзину». До подтверждения корзина должна оставаться пустой. |
| 70–90 с | Открыть корзину, показать 2 шт и итог 122 000 ₸; перезагрузить страницу. | Количество и сумма сохранились, повторного добавления нет. «Корзина хранится в SQLite и переживает перезагрузку». |

Для повторной репетиции начать новую сессию тем же способом. `sample.docx`, `sample.pdf` и `sample.jpg` возвращают те же две строки; JPEG использует записанный результат именно этого демофайла. Произвольный JPEG требует живого OCR, а скан-PDF не поддерживается.
