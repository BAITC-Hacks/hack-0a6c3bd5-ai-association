# Контур — проверяемая закупка электротоваров

Прототип консультанта для ekt.kz: подбор товаров по запросу, проверка характеристик и наличия, объяснение аналогов и корзина после явного подтверждения покупателя.

**Текущий статус:** подготовка и спецификация. Приложение ещё не реализовано; запуск и готовые функции будут документироваться после проверки каждого этапа. Планируемые возможности не являются заявлением об их готовности.
